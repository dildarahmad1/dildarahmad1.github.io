# Dildar Ahmad Portfolio

Personal portfolio published at https://dildarahmad1.github.io/.

Migrated from the existing ChatGPT Sites portfolio, preserving its design, content, CV, fonts, favicon, and social image. This is a self-contained static site with no server or build dependencies.

## Edit and preview

Edit `index.html` for content and `_next/static/css/index.Cx7dHLow.css` for styling. Run `python3 -m http.server 8080` here to preview locally.

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the site. `.nojekyll` preserves the underscore-prefixed asset directory.
